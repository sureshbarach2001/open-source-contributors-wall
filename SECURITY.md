# Security Policy

This repository is a public learning project. Please keep submissions safe for everyone.

## Never Submit Sensitive Information

Do not include:

- passwords
- API keys
- private tokens
- personal identity documents
- recovery codes
- sensitive private information

## If You Accidentally Expose a Secret

Take these steps immediately:

1. Remove the exposed value from your branch or pull request.
2. Revoke or rotate the secret.
3. Inform the maintainers if the secret was pushed publicly.

## Scope of This Repository

Contributors should only add safe public profile information inside JSON files under `contributors/`.

## Reporting a Security Concern

If you believe sensitive data has been exposed in this repository, contact the maintainers as soon as possible instead of leaving the secret visible in a public discussion.
