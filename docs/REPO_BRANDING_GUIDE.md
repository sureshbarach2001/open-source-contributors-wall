# Repository Branding Guide

This document contains the recommended public-facing branding for the GitHub repository, including the About section, topics, and social preview plan.

## Recommended Repository Name

```text
open-source-contributors-wall
```

## GitHub About Description

Use this as the main repository description:

```text
A beginner-friendly open-source repository where contributors add one JSON profile and get featured on a GitHub-style contributor wall.
```

Shorter alternative:

```text
Practice your first open-source contribution by adding one JSON profile to a public contributor wall.
```

## Recommended Website Field

If you do not have a separate landing page, leave the website field empty.

If you later publish a portfolio or community page for this project, add that URL here.

## Recommended Topics

Add these GitHub topics:

- `open-source`
- `first-contribution`
- `first-pr`
- `beginner-friendly`
- `contributors`
- `github`
- `json`
- `python`
- `github-actions`
- `community`

## Tagline Options

Use one of these lines in social posts, banners, or repo promotion:

- `One contributor. One file. One clean pull request.`
- `Make your first GitHub contribution without README conflicts.`
- `Add your profile, open a pull request, and join the contributor wall.`

## Social Preview Banner Plan

### Objective

Create a repository social preview image that looks professional on GitHub, LinkedIn, and X while clearly showing that the project is beginner-friendly and contribution-focused.

### Recommended Image Size

```text
1280 x 640 px
```

This works well for GitHub social preview images.

### Banner Content Structure

Top line:

```text
Open Source Contributors Wall
```

Supporting line:

```text
Make your first open-source contribution with one JSON file.
```

Optional footer chips:

- `Beginner Friendly`
- `First PR`
- `GitHub Wall`

### Visual Direction

Use a clean modern developer look:

- deep navy or charcoal background
- soft blue accent color
- white heading text
- subtle grid or glow pattern in the background
- 3 to 5 circular contributor avatars displayed in a wall layout
- GitHub-inspired but not copied styling

### Layout Recommendation

Left side:

- repository title
- one-line message
- 2 or 3 small badges

Right side:

- mock contributor cards or avatar circles

### Typography Direction

Use a strong clean sans-serif style such as:

- Sora
- Manrope
- Space Grotesk

### Color Palette Suggestion

- Background: `#0b1220`
- Surface: `#111827`
- Primary accent: `#38bdf8`
- Secondary accent: `#60a5fa`
- Text: `#f8fafc`
- Muted text: `#cbd5e1`

### Export Checklist

Before uploading the banner:

- keep text large and readable
- avoid too many small details
- ensure strong contrast
- keep the title in the safe center area
- preview at small size before final upload

## Launch Checklist

Before sharing the repository publicly:

1. Set the About description
2. Add the GitHub topics
3. Upload a social preview image
4. Pin the repository on your GitHub profile if needed
5. Check README formatting on GitHub
6. Test one sample contribution PR
