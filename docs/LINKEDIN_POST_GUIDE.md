# LinkedIn Post Guide

Every contributor must create a LinkedIn post before opening a pull request. This helps more beginners discover the repository and shows that you completed the contribution journey publicly.

## Why This Is Required

- it encourages learning in public
- it helps new developers find the project
- it builds a real community around contributions
- it makes the contribution feel meaningful, not mechanical

## Your Post Should Include

- a short note about your contribution
- the repository link
- a mention or tag of the repository owner
- a few relevant hashtags

## Suggested Template

```text
I just contributed to Open Source Contributors Wall, a beginner-friendly open-source repository that helps developers practice the real GitHub pull request workflow.

I completed the flow:
Fork -> Clone -> Branch -> Add JSON file -> Validate -> Commit -> Push -> Open PR

Repository:
https://github.com/sureshbarach2001/open-source-contributors-wall

#OpenSource #GitHub #FirstContribution #LearningInPublic #DeveloperCommunity
```

## After Posting

Copy the LinkedIn post URL and paste it in your pull request description.

Accepted URL formats:

- `https://www.linkedin.com/posts/...`
- `https://www.linkedin.com/feed/update/urn:li:activity:...`

Example:

```text
LinkedIn post:
https://www.linkedin.com/posts/your-post-link
```

## Tips

- keep it short and genuine
- mention what you learned
- avoid fake claims or copied stories
- make sure the repository link works
