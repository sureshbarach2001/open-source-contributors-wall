# Code of Conduct

Open Source Contributors Wall is a learning-focused repository. Everyone should feel safe, respected, and encouraged while practicing open-source contribution.

## Our Standard

We expect contributors and maintainers to:

- be respectful and patient
- support beginners with clear feedback
- keep pull requests honest and focused
- communicate professionally
- help maintain a welcoming learning environment

## Unacceptable Behavior

These behaviors are not allowed:

- harassment or personal attacks
- abusive or insulting language
- spam or self-promotion without contribution value
- fake contributor profiles
- misleading contribution claims
- editing another contributor's file without a valid reason
- sharing private or sensitive information

## Maintainer Responsibility

Maintainers may:

- request changes
- close issues or pull requests
- remove spam or misleading content
- block repeat offenders when necessary

## Reporting

If you notice harmful behavior, open an issue or contact the maintainers through the repository discussion channel you were given.

## Community Goal

This project exists to help people learn by doing. Kindness, honesty, and clear collaboration matter as much as valid code and valid JSON.
